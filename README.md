# Irrigation Trial PWA - تطبيق تجربة الري

تطبيق ويب أوفلاين احترافي قابل للتثبيت على كافة الأنظمة (Android, iOS, Windows, macOS) لحساب وتحليل تجارب الري للبيفوتات الزراعية بدقة عالية.

## 🌟 المميزات الرئيسية
1. **يعمل بدون إنترنت بالكامل (Offline-First PWA)**: إمكانية التثبيت كـ Progressive Web App مع شارات مخصصة لسطح المكتب والشاشة الرئيسية.
2. **إدارة وحفظ متعدد للبيفوتات**: دعم حفظ واستدعاء أكثر من 10 بيفوتات زراعية في الذاكرة المحلية (LocalStorage) مع إمكانية التنقل السريع، التعديل، والحذف.
3. **دعم الثيمات واللغات**: التبديل الفوري بين ثيم النهار والليل (Dark/Light Mode) وتغيير اللغة بين العربية والإنجليزية دون التداخل مع لغة الجهاز.
4. **تصدير واستيراد البيانات**: تصدير تقارير Excel شاملة مع التحليل الإحصائي تلقائياً، وحفظ مخططات رسم SVG عالية الجودة.
5. **قسم تواصل المطور**: مربع تواصل تفاعلي يتيح التوجيه التلقائي للتطبيقات الرسمية على الأندرويد و iOS (LinkedIn, Facebook, X, WhatsApp, Telegram, Gmail).

## 📁 هيكل الملفات
- `index.html`: الواجهة الرئيسية والمناطق التفاعلية.
- `styles.css`: التنسيقات والاستجابة للثيم المظلم والمضيء.
- `app.js`: البرمجة والعمليات الإحصائية وحفظ البيانات المحلية.
- `manifest.json`: إعدادات تثبيت التطبيق والشعار.
- `sw.js`: الـ Service Worker لإتاحة العمل بدون إنترنت.
- `icon-192.png` & `icon-512.png`: شعارات التطبيق بدقة 192x192 و 512x512 في المجلد الرئيسي.
